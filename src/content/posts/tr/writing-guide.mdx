## Kod blokları

Kod bloklarında syntax renklendirme, kopyala butonu ve isteğe bağlı dosya adı bulunur:

```swift title="BudgetStore.swift" {3-5}
@Observable
final class BudgetStore {
    var entries: [Entry] = []

    func add(_ entry: Entry) {
        entries.append(entry)
    }
}
```

Satırlar eklenmiş ya da silinmiş olarak işaretlenebilir:

```ts del={2} ins={3}
export function total(entries: Entry[]) {
  return entries.reduce((sum, e) => sum + e.amount);
  return entries.reduce((sum, e) => sum + e.amount, 0);
}
```

Terminal komutları terminal çerçevesiyle gösterilir:

```bash
npm run dev
```
